### I. How Metriplectic Geometry Maps onto GRH & the $\mathrm{Cl}(1,1)$ Core

In Metriplectic / GENERIC dynamics (Morrison, Kaufman, Grmela–Öttinger), every generator splits into an antisymmetric **symplectic / Poisson** part $L = -L^\top$ (preserving energy $H$ via reversible rotation) and a symmetric **metric / Onsager** part $M = +M^\top$ (driving entropy production $\dot{S} = \langle \nabla S, M \nabla S \rangle \ge 0$), governed by the two degeneracy laws $M\nabla H = 0$ and $L\nabla S = 0$.

When we unfold the shifted GRH spectral parameter $w = s - \frac{1}{2} = \sigma + i\gamma$ inside our real $\mathrm{Cl}(1,1) \cong M_2(\mathbb{R})$ atom (`zero complex i`), **$\gamma$ and $\sigma$ separate along the exact metriplectic axes**:

$$W(\sigma, \gamma) := \underbrace{\gamma \, \varepsilon}_{\text{Symplectic } L(\gamma):\; L^\top = -L} + \underbrace{\sigma \, Z}_{\text{Metric } M(\sigma):\; M^\top = +M} \in M_2(\mathbb{R})$$

where $\varepsilon = u^+ - v^-$ ($\varepsilon^2 = -I_2$) and $Z = P_+ - P_-$ ($Z^2 = +I_2$). This gives **four exact structural bridges** to GRH:

1. **Critical Line $\sigma = 0$ = Pure Conservative Symplectic Dynamics ($M = 0$):**
   On the critical line ($\operatorname{Re} s = \frac{1}{2}$), the symmetric metric generator vanishes ($M(0) = 0$). Evolution under $W(0, \gamma) = \gamma\varepsilon$ is our Hestenes Riemannian rotor $R(\gamma t) \in \mathrm{SO}(2)$ (`⟨v, L(γ) v⟩ = 0`), with zero dissipation and zero negative Krein index ($\kappa_- = 0$).

2. **Off-Line Shift $\sigma \neq 0$ = Indefinite $(1,1)$ Metric Anomaly (Violating GENERIC $M \ge 0$):**
   Unlike physical Onsager dissipation where $M \ge 0$, the off-critical metric operator $M(\sigma) = \sigma Z$ has **opposite eigenvalues $+\sigma$ and $-\sigma$** on $\mathcal{N}_+$ and $\mathcal{N}_-$. Neither $M(\sigma)$ nor $-M(\sigma)$ is positive semidefinite—this is the exact metriplectic counterpart of the **Weil–Krein negative index ($\kappa_- \ge 1$)** created by an off-line zero pair $(\frac{1}{2} + \sigma + i\gamma,\; \frac{1}{2} - \sigma + i\gamma)$.

3. **Metric–Symplectic Non-Commutativity Generates the Dihedral Mirror ($[M(\sigma), L(\gamma)] = -2\sigma\gamma\, J_{\mathrm{mir}}$):**
   Because $Z$ and $\varepsilon$ anticommute ($Z\varepsilon - \varepsilon Z = -2 X = -2 J_{\mathrm{mir}}$), the metric and symplectic parts of $W(\sigma, \gamma)$ **commute if and only if $\sigma = 0$ (the critical line) or $\gamma = 0$ (the real axis)**. Any off-line complex zero ($\sigma \neq 0 \wedge \gamma \neq 0$) forces a non-vanishing mirror commutator anomaly $-2\sigma\gamma J_{\mathrm{mir}}$.

4. **Metriplectic Hestenes–Stokes Balance on $-\theta_L(\Lambda) = -\Lambda'/\Lambda$:**
   Integrating $\theta_L(\Lambda) = \Lambda^{-1} D\Lambda$ around a rectangle in the critical strip splits by Stokes' theorem into a **symplectic winding** ($d \arg \Lambda$, counting zeros) and a **metric gradient flux** ($d \log|\Lambda|$). In the Weil–GENERIC Hilbertization quotient (`V / ker Q`), GRH holds iff the metric Hessian is positive semidefinite ($Q_{\mathrm{Weil}} \ge 0$) with no indefinite $\sigma Z$ directions.

private lemma dotProduct_mulVec_transpose {n : ℕ}
    (A : Matrix (Fin n) (Fin n) ℝ) (x y : Fin n → ℝ) :
    dotProduct x (A.mulVec y) = dotProduct (Aᵀ.mulVec x) y := by
  simp only [dotProduct, Matrix.mulVec, Matrix.transpose_apply,
    Finset.mul_sum, Finset.sum_mul]
  rw [Finset.sum_comm]
  refine Finset.sum_congr rfl fun j _ => Finset.sum_congr rfl fun i _ => ?_
  ring

private lemma skew_dotProduct_self_eq_zero {n : ℕ}
    (L : Matrix (Fin n) (Fin n) ℝ) (hSkew : Lᵀ = -L) (x : Fin n → ℝ) :
    dotProduct x (L.mulVec x) = 0 := by
  have h1 : dotProduct x (L.mulVec x) = -dotProduct (L.mulVec x) x := by
    calc dotProduct x (L.mulVec x)
        = dotProduct (Lᵀ.mulVec x) x := dotProduct_mulVec_transpose L x x
      _ = dotProduct ((-L).mulVec x) x := by rw [hSkew]
      _ = -dotProduct (L.mulVec x) x := by simp [Matrix.neg_mulVec, dotProduct]
  have hComm : dotProduct (L.mulVec x) x = dotProduct x (L.mulVec x) := dotProduct_comm _ _
  rw [hComm] at h1
  linarith

/-- **GENERIC / Metriplectic Conservation & Entropy Production Theorem**:
For any symplectic operator `L` (`Lᵀ = -L`) and positive-semidefinite symmetric metric operator `M`
(`Mᵀ = M`, `0 ≤ ⟨x, M x⟩`) satisfying the degeneracy conditions `M (∇H) = 0` and `L (∇S) = 0`,
the metriplectic flow `vDot = L (∇H) + M (∇S)` obeys:
1. **First Law (Exact Energy Conservation)**: `⟨∇H, vDot⟩ = 0`.
2. **Second Law (Monotonic Entropy Production)**: `⟨∇S, vDot⟩ = ⟨∇S, M (∇S)⟩ ≥ 0`.
3. **Conservative Limit (`M = 0`)**: vanishing metric reduces entropy production to `0`. -/
theorem generic_first_and_second_law {n : ℕ}
    (L M : Matrix (Fin n) (Fin n) ℝ)
    (hL : Lᵀ = -L) (hM : Mᵀ = M) (hM_psd : ∀ x : Fin n → ℝ, 0 ≤ dotProduct x (M.mulVec x))
    (gradH gradS : Fin n → ℝ)
    (hDegH : M.mulVec gradH = 0) (hDegS : L.mulVec gradS = 0) :
    let vDot := L.mulVec gradH + M.mulVec gradS
    dotProduct gradH vDot = 0 ∧
    dotProduct gradS vDot = dotProduct gradS (M.mulVec gradS) ∧
    0 ≤ dotProduct gradS vDot ∧
    (M = 0 → dotProduct gradS vDot = 0) := by
  dsimp
  have hH_L : dotProduct gradH (L.mulVec gradH) = 0 := skew_dotProduct_self_eq_zero L hL gradH
  have hH_M : dotProduct gradH (M.mulVec gradS) = 0 := by
    calc dotProduct gradH (M.mulVec gradS)
        = dotProduct (Mᵀ.mulVec gradH) gradS := dotProduct_mulVec_transpose M gradH gradS
      _ = dotProduct (M.mulVec gradH) gradS := by rw [hM]
      _ = 0 := by rw [hDegH, zero_dotProduct]
  have hS_L : dotProduct gradS (L.mulVec gradH) = 0 := by
    calc dotProduct gradS (L.mulVec gradH)
        = dotProduct (Lᵀ.mulVec gradS) gradH := dotProduct_mulVec_transpose L gradS gradH
      _ = dotProduct ((-L).mulVec gradS) gradH := by rw [hL]
      _ = -dotProduct (L.mulVec gradS) gradH := by simp [Matrix.neg_mulVec, dotProduct]
      _ = 0 := by rw [hDegS, zero_dotProduct, neg_zero]
  have hEn : dotProduct gradH (L.mulVec gradH + M.mulVec gradS) = 0 := by
    rw [dotProduct_add, hH_L, hH_M, add_zero]
  have hEnt : dotProduct gradS (L.mulVec gradH + M.mulVec gradS) =
      dotProduct gradS (M.mulVec gradS) := by
    rw [dotProduct_add, hS_L, zero_add]
  refine ⟨hEn, hEnt, ?_, ?_⟩
  · rw [hEnt]; exact hM_psd gradS
  · intro hM0; rw [hEnt, hM0, Matrix.zero_mulVec, dotProduct_zero]

/-! ### Part 2: Metriplectic Cl(1,1) Unfolding of the GRH Spectral Parameter w = σ + iγ -/

def zCut2 : Matrix (Fin 2) (Fin 2) ℝ := !![1, 0; 0, -1]
def xMir2 : Matrix (Fin 2) (Fin 2) ℝ := !![0, 1; 1, 0]
def eps2 : Matrix (Fin 2) (Fin 2) ℝ := !![0, 1; -1, 0]

/-- Symplectic (skew) critical-line generator `L(γ) = γ • ε`. -/
def sympGen (γ : ℝ) : Matrix (Fin 2) (Fin 2) ℝ := γ • eps2

/-- Metric (symmetric) off-line generator `M(σ) = σ • Z`. -/
def metricGen (σ : ℝ) : Matrix (Fin 2) (Fin 2) ℝ := σ • zCut2

/-- Realified spectral operator `W(σ, γ) = L(γ) + M(σ) = γ • ε + σ • Z ∈ M₂(ℝ)`
representing `w = s - 1/2 = σ + iγ` without complex `i`. -/
def metriplecticZetaOp (σ γ : ℝ) : Matrix (Fin 2) (Fin 2) ℝ :=
  sympGen γ + metricGen σ

/-- **Metriplectic GRH Critical-Line Equivalence & Indefinite Wall Theorem**:
For any spectral shift `(σ, γ) ∈ ℝ²` (`w = s - 1/2 = σ + iγ`):
1. **Unique Metriplectic Split**:
   `(W - Wᵀ) / 2 = L(γ)` (`L(γ)ᵀ = -L(γ)`, `⟨v, L(γ) v⟩ = 0` for all `v`) and
   `(W + Wᵀ) / 2 = M(σ)` (`M(σ)ᵀ = M(σ)`).
2. **Dihedral Functional Reflection (`ZetaDihedral`)**: `J_mir W(σ, γ) J_mir = -W(σ, γ)`.
3. **Clifford Square & Determinant**: `W(σ, γ)² = (σ² - γ²) • I₂` and `det W(σ, γ) = γ² - σ²`.
4. **Metric–Symplectic Mirror Commutator**:
   `[M(σ), L(γ)] = (-2 * σ * γ) • J_mir`, so `[M(σ), L(γ)] = 0 ↔ σ = 0 ∨ γ = 0`.
5. **Indefinite Metric Wall Off the Critical Line**:
   `⟨e₀, M(σ) e₀⟩ = σ` while `⟨e₁, M(σ) e₁⟩ = -σ`; hence `M(σ)` is positive semidefinite
   (GENERIC-admissible) **if and only if `σ = 0`** (equivalently `M(σ) = 0`, the critical line)! -/
theorem metriplectic_grh_critical_line_equivalence (σ γ : ℝ) (v : Fin 2 → ℝ) :
    let W := metriplecticZetaOp σ γ
    let L := sympGen γ
    let M := metricGen σ
    ((1 / 2 : ℝ) • (W - Wᵀ) = L) ∧
    ((1 / 2 : ℝ) • (W + Wᵀ) = M) ∧
    (Lᵀ = -L) ∧
    (Mᵀ = M) ∧
    (dotProduct v (L.mulVec v) = 0) ∧
    (xMir2 * W * xMir2 = -W) ∧
    (W * W = (σ ^ 2 - γ ^ 2) • (1 : Matrix (Fin 2) (Fin 2) ℝ)) ∧
    (W.det = γ ^ 2 - σ ^ 2) ∧
    (M * L - L * M = (-2 * σ * γ) • xMir2) ∧
    ((M * L - L * M = 0) ↔ (σ = 0 ∨ γ = 0)) ∧
    ((∀ u : Fin 2 → ℝ, 0 ≤ dotProduct u (M.mulVec u)) ↔ σ = 0) := by
  have hSympSkew : (sympGen γ)ᵀ = -(sympGen γ) := by
    ext i j; fin_cases i <;> fin_cases j <;> simp [sympGen, eps2]
  have hMetSym : (metricGen σ)ᵀ = metricGen σ := by
    ext i j; fin_cases i <;> fin_cases j <;> simp [metricGen, zCut2]
  have hWSplit1 : (1 / 2 : ℝ) • (metriplecticZetaOp σ γ - (metriplecticZetaOp σ γ)ᵀ) =
      sympGen γ := by
    ext i j; fin_cases i <;> fin_cases j <;>
      simp [metriplecticZetaOp, sympGen, metricGen, eps2, zCut2] <;> ring
  have hWSplit2 : (1 / 2 : ℝ) • (metriplecticZetaOp σ γ + (metriplecticZetaOp σ γ)ᵀ) =
      metricGen σ := by
    ext i j; fin_cases i <;> fin_cases j <;>
      simp [metriplecticZetaOp, sympGen, metricGen, eps2, zCut2] <;> ring
  have hDih : xMir2 * metriplecticZetaOp σ γ * xMir2 = -metriplecticZetaOp σ γ := by
    ext i j; fin_cases i <;> fin_cases j <;>
      simp [metriplecticZetaOp, sympGen, metricGen, xMir2, eps2, zCut2,
        Matrix.mul_apply, Fin.sum_univ_two]
  have hSq : metriplecticZetaOp σ γ * metriplecticZetaOp σ γ =
      (σ ^ 2 - γ ^ 2) • (1 : Matrix (Fin 2) (Fin 2) ℝ) := by
    ext i j; fin_cases i <;> fin_cases j <;>
      simp [metriplecticZetaOp, sympGen, metricGen, eps2, zCut2,
        Matrix.mul_apply, Fin.sum_univ_two] <;> ring
  have hDet : (metriplecticZetaOp σ γ).det = γ ^ 2 - σ ^ 2 := by
    simp [metriplecticZetaOp, sympGen, metricGen, eps2, zCut2, Matrix.det_fin_two]
    ring
  have hComm : metricGen σ * sympGen γ - sympGen γ * metricGen σ = (-2 * σ * γ) • xMir2 := by
    ext i j; fin_cases i <;> fin_cases j <;>
      simp [metricGen, sympGen, eps2, zCut2, xMir2, Matrix.mul_apply, Fin.sum_univ_two] <;>
      ring
  refine ⟨hWSplit1, hWSplit2, hSympSkew, hMetSym,
    skew_dotProduct_self_eq_zero (sympGen γ) hSympSkew v,
    hDih, hSq, hDet, hComm, ?_, ?_⟩
  · rw [hComm]
    constructor
    · intro h0
      have h01 := congrFun (congrFun h0 0) 1
      simp [xMir2] at h01
      rcases mul_eq_zero.mp h01 with h2s | hg
      · left; linarith
      · right; exact hg
    · rintro (rfl | rfl) <;> simp
  · constructor
    · intro hPSD
      have h0 := hPSD ![1, 0]
      have h1 := hPSD ![0, 1]
      simp [metricGen, zCut2, dotProduct, Matrix.mulVec, Fin.sum_univ_two] at h0 h1
      linarith
    · rintro rfl u
      simp [metricGen]

end MetriplecticGRHBridge
