# Plabic/Krein share: exhaustive normalized archetype catalog

## Scope and provenance

This catalog consolidates the **18 C-level** and **28 A-level** archetype labels
in the checked-in extraction of share
`6ad7a6e8-cf08-83eb-9d07-48cba614b860`. These are two overlapping levels of
classification, not 46 independent theorems: C-level entries are broader
families; A-level entries refine selected finite graph, operator, path,
thermodynamic, and neural-contract families.

The extraction records 44 nonempty user prompt windows (P00–P43), 659
nonempty assistant records, and 3,501 decoded mapping nodes. The raw payload is
not present in this checkout, and live-share verification was not completed.
Thus “exhaustive” here means **every archetype ID in the checked-in C0–C17 and
A0–A27 normalized maps**, not every possible implication in the conversation,
not hidden/internal reasoning, and not independently recovered attachments or
link contents. The exact prompt archive, source-qualified owner ledger, and
reproducibility manifest remain the provenance references below.

## Non-edges: interpretations explicitly not admitted

The extraction does not prove any of these identifications:

- Krein sheets/projectors = a topological Klein bottle;
- scalar q-commutation = a thermal partition function or boson/fermion theory;
- finite BKM form = para-Kähler metric;
- Clifford/Zorn carrier = Nambu electromagnetism;
- local Plabic mutation = neural backpropagation;
- MaxCal optimizer fields = existence or uniqueness of an optimizer;
- all C/A carriers = one common representation;
- local Cl11 conjugation = every plabic square move;
- equality of nonzero Gram eigenvalue multiplicities (A10 remains vector-level here).
