## Rule

An open problem here should be one of:

- a missing bridge between current owner surfaces
- a theorem target not yet formalized
- a tooling gap that blocks trustworthy verification

It should not be a frozen dump of old speculative prose.

## Current Problem Types

- connect active Lean trunks more cleanly
- reduce warning or wrapper debt without breaking owner structure
- keep DAG and LeanTrail surfaces truthful to the current code
- convert useful historical ideas into concrete, verifiable work
