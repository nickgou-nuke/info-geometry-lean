# Matrix amplification verification

This focused Lake project checks the actual sources under `lean/`. It uses
the root toolchain and the exact Mathlib revision recorded in the root
manifest. Native dependency checkouts are shared within this checkout under
`.lake/packages`; builds use the repository's shared build lock.

```bash
python3 verification/matrix-amplification/check.py exe cache get
python3 verification/matrix-amplification/check.py build
python3 verification/matrix-amplification/check.py env lean \
  lean/InfoGeometry/Categorical/MatrixAmplificationAudit.lean
```

`build` selects the audit module and its complete import closure. The final
command freshly elaborates the audit even if its compiled artifact is already
cached. It enumerates all declarations owned by the following modules,
including generated and private declarations, and rejects unsafe/partial
declarations or axiom dependencies outside `propext`, `Classical.choice`, and
`Quot.sound`:

- `InfoGeometry.Algebra.MatrixAmplification`
- `InfoGeometry.Categorical.SequentialRingColimit`
- `InfoGeometry.Categorical.MatrixAmplificationTower`

Source-generation and audit helpers are not proof authorities. A successful
compiler result and completed audit markers are required. The owner filter is
generated by `tools/quality/reviewed_audit_source.py`; it must be kept in sync
if mathematical owner modules are added or removed.

This project does not certify unrelated default targets, root path packages,
the categorical umbrella's other imports, or analytic operator completions.
The repository's publication gate remains a separate check.
