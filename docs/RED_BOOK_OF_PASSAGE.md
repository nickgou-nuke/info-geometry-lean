# The Red Book of Passage
## A Method for Translating Symbolic Material into Formal Closure

This document treats the Markdown corpus as a natural-language logical system.
It is not a proof surface. It is a disciplined method for moving from
exploration to theorem.

### 1. First Law

The repository keeps two coupled registers:

- Black register: symbolic pressure, dream material, analogical reach.
- Red register: explicit definitions, typed claims, bridge obligations.

Neither register is optional.
The first generates candidates. The second decides admissibility.

### 2. Epistemic Split (Jung / Pauli)

Working rule:

- exploration may be Jungian
- closure must be Pauli

Operationally:

- Symbolic text may propose objects, symmetries, and metaphors.
- Only Lean-certified declarations can assert existence, equality, invariance,
  or transport closure.

### 3. Passage Operators

Every new idea must pass through the same operators, in order.

1. `Evoke`: isolate the symbolic motif from prose.
2. `Extract`: rewrite motif as candidate mathematical object.
3. `Type`: assign representation depth (`count` ... `thermo`).
4. `Anchor`: bind candidate to owner modules (no new owner by rhetoric).
5. `Bridge`: state explicit comparison theorem (or obstruction theorem).
6. `Close`: compile, audit, and record proof status.
7. `Return`: write plain-language interpretation back into docs.

No step may be skipped.

### 4. Linguistic Safety Rules

The corpus may use mythic language, but closure claims must avoid inflation.

Forbidden in closure text:

- "is unified" without a compiled bridge theorem
- "is invariant" without an explicit invariant theorem
- "is derived" when the layer only restates a definition

Required in closure text:

- owner file path
- theorem/definition identifier
- declared depth
- dependency direction (what it uses, what it discharges)

### 5. Black -> Red Contract

A black-book chapter is considered integrated only when it has:

- a chapter-level symbolic summary,
- one or more candidate formal targets,
- a translation note naming owner/translator/coherence surfaces,
- a closure state: `open`, `bridge-drafted`, `compiled`, or `obstructed`.

If no formal target exists yet, keep the chapter as raw intake.
Do not purge it.

### 6. Ontology and Epistemology of the Corpus

The corpus already defines a coherent natural-language ontology:

- measurement is relational and projective,
- structure is layered by representation depth,
- transport links local operators to global readouts,
- topological statements are carried by explicit invariants,
- narratives are generators of hypotheses, not proof substitutes.

Its epistemology is a two-loop system:

- generative loop (novel hypotheses),
- adjudicative loop (kernel closure).

### 7. Writing Discipline for the Next Red Book Cycle

When drafting new red-book text:

1. Start from one symbolic tension only.
2. Name the exact Lean owner surface before introducing metaphor.
3. End with a finite translation backlog:
   - one owner extension, or
   - one adjacent bridge theorem, or
   - one explicit obstruction theorem.

This keeps style intense without losing formal traction.

### 8. Practical Outcome

The goal is not to suppress the black books.
The goal is to convert them into a durable hypothesis engine whose outputs are
machine-checkable and cumulative.
