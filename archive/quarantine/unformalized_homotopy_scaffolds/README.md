# Unformalized homotopy and TQFT scaffolds

These Lean drafts are preserved here as `.lean.disabled` files because their
theorem declarations asserted `True` with `trivial`, and their structures used
`True` fields in place of the stated categorical, homotopy, or operator-algebra
constructions. They were not kernel-checked formalizations of the surrounding
claims. The files are excluded from the active Lean package and its umbrellas;
the original source text remains available for future formalization against
actual Mathlib carriers and maps.

Quarantined drafts: `CategoricalSpectrumTQFT`, `HolographyBulkBoundary`,
`InvertiblePhases`, `OmegaSpectrum`, `ProjectiveTQFT`, `QuantumSpinSystem`,
and `VecNTQFT`.
