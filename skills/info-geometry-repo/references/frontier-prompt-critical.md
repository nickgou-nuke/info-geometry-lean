# Frontier Prompt (Critical)

Use this variant when reviewing candidate bridge statements skeptically.

## Questions to ask

- Is the candidate a real lower bridge or only a wrapper?
- Does it belong in the proposed owner file?
- Is there already a lower theorem in the repo that makes it redundant?
- Would proving it actually reduce shell pressure or only move it?
- Is the statement constructive, or does it only restate hypotheses?
