This file records the current local policy for Hermes-style intake and packet
handling around the repository.

## Current Role

Hermes is not a proof authority. It is a research and intake sidecar around the
main Lean and tooling surfaces.

## Rules

- proposals remain non-canonical until reproduced in current code
- packet workflows live under `handover/injections/`
- implementation and verification still route through current Lean files and
  maintained scripts
- generated artifacts remain snapshots, not source of truth

## Current Workflow

1. create or inspect a packet under `handover/injections/`
2. map it to current owner files
3. implement in `lean/` or maintained tooling
4. verify with current build commands

Useful commands:

```bash
python3 tools/infra/injection_status.py --list gated
lake script run changedVerify
lake script run dagDoctor
```
