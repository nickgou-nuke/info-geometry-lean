### 1. Vector Search + Graph AQL (Retrieval Layer)
Use this AQL query to perform semantic retrieval over the aiClaw embeddings while leveraging ArangoDB's native graph traversal to pull contextual metadata (authors, citations, linked topics).

```aql
// Final AQL RAG Query
FOR doc IN literature_nodes
  SEARCH ANALYZER(
    COSINE_SIMILARITY(doc.embedding, @query_embedding) > 0.85,
    "vector_analyzer"
  )
  SORT COSINE_SIMILARITY(doc.embedding, @query_embedding) DESC
  LIMIT 5

  // Graph traversal leap
  FOR v, e IN 1..2 OUTBOUND doc citation_edges
  RETURN {
    primary_text: doc.content,
    similarity_score: COSINE_SIMILARITY(doc.embedding, @query_embedding),
    linked_context: v.content,
    relationship: e.type
  }
```

### 2. Python Injection Engine (Data Layer)
```python
import json
from arango import ArangoClient
from sentence_transformers import SentenceTransformer

# Initialize DB and Embedding Model
client = ArangoClient(hosts='http://localhost:8529')
db = client.db('aiclaw_rag', username='root', password='password')
model = SentenceTransformer('all-MiniLM-L6-v2')

def ingest_aiclaw_literature(filepath):
    with open(filepath, 'r') as f:
        literature_batch = json.load(f)

    collection = db.collection('literature_nodes')

    for item in literature_batch:
        # Direct embedding generation
        vector = model.encode(item['content']).tolist()

        # Inject into ArangoDB
        collection.insert({
            "_key": item['doc_id'],
            "title": item['title'],
            "content": item['content'],
            "embedding": vector,
            "source": "aiClaw_google_ai"
        })

# Execute pipeline
ingest_aiclaw_literature('./aiclaw_downloads.json')

By combining vector search with native graph traversal in ArangoDB, you bypass the limitations of traditional vector-only databases. Your setup allows the agent to not only pull semantically similar literature captured by aiClaw but also navigate citation networks, multi-hop reference lineages, and author relationships natively in a single query. However, to make this specific AQL syntax functional and compatible with ArangoDB's real-world execution engine, we need to address two critical technical requirements:

   1. Vector Index Syntax Constraints: In ArangoDB, vector search is managed through the SEARCH statement using a specific ArangoSearch view (or index) syntax. The function COSINE_SIMILARITY cannot be directly embedded inside the SEARCH filtering condition like a boolean expression in standard AQL. It must be computed via a dedicated vector index macro (VANGUARD / HNSW syntax depending on the ArangoDB version) or calculated inline. [4]
   2. Graph Traversal Collision: When executing a graph traversal (FOR v, e IN 1..2 OUTBOUND doc) immediately following a SEARCH statement on the same collection, the initial document context (doc) must be bound correctly to a node in a defined graph or edge collection list.

Here is the exact Python extraction script to make `aiClaw` ingest the Meta ATLAS repository into your Graph RAG:

#### 🐍 1. The aiClaw Lean-to-ArangoDB Seeder (`seed_lean_atlas.py`)

```python
import os
import json
import re
from arango import ArangoClient
from sentence_transformers import SentenceTransformer

# Initialize DB and ONNX Embedder (Matches our TypeScript extension natively)
client = ArangoClient(hosts='http://localhost:8529')
db = client.db('aiclaw_rag', username='root', password='password')
model = SentenceTransformer('all-MiniLM-L6-v2')

def ingest_lean_atlas(repo_path):
    """
    Parses the facebookresearch/atlas-lean repository.
    Extracts theorems and their dependencies to build a Formal Logic Graph.
    """
    nodes_coll = db.collection('literature_nodes')
    edges_coll = db.collection('citation_edges')

    # Regex to find Lean 4 theorems and definitions
    theorem_pattern = re.compile(r'(theorem|lemma|def)\s+([a-zA-Z0-9_]+)([\s\S]*?)(:=)')

    for root, _, files in os.walk(repo_path):
        for file in files:
            if file.endswith('.lean'):
                filepath = os.path.join(root, file)
                with open(filepath, 'r', encoding='utf-8') as f:
                    content = f.read()

                matches = theorem_pattern.findall(content)
                for match in matches:
                    declaration_type = match[0]
                    name = match[1]
                    body = match[2].strip()

                    full_text = f"{declaration_type} {name} {body}"
                    vector = model.encode(full_text).tolist()

                    # 1. Upsert the Formal Logic Node
                    doc = {
                        "_key": name, # Use theorem name as unique ID
                        "title": name,
                        "content": full_text,
                        "embedding": vector,
                        "source": "facebookresearch/atlas-lean"
                    }
                    try:
                        nodes_coll.insert(doc)
                    except:
                        nodes_coll.update_match({'_key': name}, doc)

                    print(f"✅ Ingested formally verified node: {name}")

                    # 2. Extract dependencies (naive reference matching for the graph)
                    # If this theorem mentions previous lemmas, create a 1..2 OUTBOUND edge
                    words = set(re.findall(r'[a-zA-Z0-9_]+', body))
                    for word in words:
                        if nodes_coll.has(word) and word != name:
                            edge = {
                                "_from": f"literature_nodes/{name}",
                                "_to": f"literature_nodes/{word}",
                                "type": "formal_dependency"
                            }
                            try:
                                edges_coll.insert(edge)
                            except:
                                pass

if __name__ == "__main__":
    # Assuming you git cloned https://github.com/facebookresearch/atlas-lean locally
    ingest_lean_atlas("./atlas-lean")
```

            });
