## Native carriers and notation

The algebraic statements use an arbitrary associative R-algebra A:
[CommRing R] [Ring A] [Algebra R A]. Commutativity of A is never assumed.
The concrete pairing and metric statements use the entire Matrix n n R
or Matrix n n ℂ, with finite indices and decidable equality.

C_U is native LieAlgebra.ad R A U.
J_U is the existing Core.JordanMultiplicationClosure.jordanLeft U.
L_U and R_U are native left and right multiplication.
No replacement operator structures or public shorthand wrappers are introduced.

For comparison in this document only, put
D = -(C_U C_V + C_V C_U),
F = C_U J_V - C_V J_U,
H = UV + VU, K = [U,V], and G = C_H + D.
Multiplication of endomorphisms is composition.

For an idempotent p, S is the existing Core.PeirceGrading.reflection p.
The directed coefficients are actual opposite Peirce corners
U=p a (1-p), V=(1-p) b p. Their opposite orientation matters for D(S).

The bilinear form is the native composition
(LinearMap.mul R (Matrix n n R)).compr₂ (Matrix.traceLinearMap n R R).
Its value is trace(XY). Adjoint assertions use LinearMap.IsAdjointPair
and LinearMap.IsSkewAdjoint, with order reversal supplied by Mathlib.

The complex metric uses the same native matrix norm and inner-product
instances at weight one as PR261. Its metric adjoint is LinearMap.adjoint.
The bilinear trace form and this sesquilinear metric remain distinct.
