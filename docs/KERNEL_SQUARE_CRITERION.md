# Kernel-square stability criterion

The KreinHodgeObstruction owner exhibits a nonzero square-zero Krein-self-adjoint
continuous operator with unequal kernels for D and D². The replacement is over
an arbitrary ring module and native LinearMap: ker(f∘f)=ker(f) iff range(f) and
ker(f) are disjoint. In the square-zero case stability is equivalent to f=0.
The companion audit uses disjointness ⇒ stability contrapositively for the actual doubled-space nullDirac,
not a coordinate proxy. No positivity, finite dimension, or adjoint is assumed.
