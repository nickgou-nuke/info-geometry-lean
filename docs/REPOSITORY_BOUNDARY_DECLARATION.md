# Repository Boundary Declaration

These are hard repository firewalls.

1. No concrete Souriau coadjoint-orbit realization is currently proved for
   `G2(2)`, `G2*`, or `Spin(5,5)`.
   Existing Souriau files are abstract dual-pair/cocycle interfaces unless
   explicit `Ad`, `Ad*`, cocycle, and Fenchel/Massieu data are supplied.

2. No source-side theorem currently proves split-Clifford data produces a full
   Heisenberg current witness.
   Current bridge files are conditional adapters that consume:
   `J`, `trunc`, and `comm`.

3. Zorn split-octonion cells are not ordinary associative `2×2` block
   matrices.
   They use a custom nonassociative product. `detZ` multiplicativity belongs to
   the split-octonion composition lane, not ordinary matrix determinant algebra.

4. Twistor space is not definitionally equal to split octonions.
   The intended theorem target is Penrose's carried-structure statement:
   quantized twistor algebra carries split-octonion and `G2*` structure.
