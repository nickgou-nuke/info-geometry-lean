# Hermes Bootstrap Policy (v0)

## Lane Split
- Default execution lane: `openai-codex`.
- Ideation lane: `gemini` only when explicitly requested by the operator.
- Default large-context interactive lane: `openai-codex/gpt-5.4`.
- Local active planner lane: `Qwen/Qwen3.6-35B-A3B-FP8` on `127.0.0.1:8001` when the SparkRun resident is up.

## Hard Rules
- Gemini outputs are proposal-only until Codex reproduces and validates.
- Do not auto-route to Gemini CLI.
- Do not use `google-gemini-cli`, Gemini Code Assist OAuth, Antigravity OAuth, token extraction, token harvesting, proxying, or quota piggybacking.
- Gemini may be used only through explicit operator command and only via normal official CLI/API access already present in the operator environment.
- Agent Gemini CLI use must go through `tools/infra/run_gemini_guarded.sh`; direct `gemini` calls are operator-only.
- Gemini CLI is an irregular dreaming sidecar: infrequent, jittered, non-canonical, and never a polling backend.
- **Strong Gravitation**: Planning context MUST be extracted from the ArangoDB DAG of proven code (`arango_gravity_context.py`).
- **Axiom-Surface Seal**: All agentic tactics must be verified via the token-free REPL bridge (`lean_interact_wrapper.py`) against the kernel.
- **Multilingual Bridge Fidelity**: Comments/docstrings that map SymPy, Python, Lean 4, LaTeX, and physics-of-information terminology are representation substrate. Do not shorten them by density heuristics; preserve, correct, or expand them unless they are stale or false.
- Canonical edits (`lean/InfoGeometry/Canonical/*`) require Codex execution lane.
- Post-edit verification must run targeted `lake build` surfaces before any broad build.
- `artifacts/*` are generated outputs and are not committed as source of truth.

## Injection Workflow
1. Create packet in `handover/injections/raw/`.
2. Distill to `distilled/`.
3. Translate to repo-native mapping in `translated/`.
4. Gate in `gated/` with explicit build targets.
5. Promote to `accepted/` only after implementation and verification.
