# Review scope

This stacked review contains the explicit split `(5,5)` quadratic carrier,
its orthogonal Lie algebra, contact five-grading, block bigrading, parity,
Heisenberg radical brackets, five-grade projections, boundary selection,
Witt null frame, independent Pin readouts, common CAR--CCR representation,
crosscap covariance, zero-grade brackets, capstone, audit, and verification
script.

The generic symplectic/Freudenthal contact algebra in the base is not identified
with the new orthogonal contact algebra. The `1,12,19,12,1` theorem is a finite
homogeneous generator census, not yet a native basis/finrank theorem.
