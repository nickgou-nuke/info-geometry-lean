From the repository root, run the inference CLI on observed character profiles or native term-digest snapshots, then import its repo-structural-affinity/v1 output here.

python3 tools/repository_evolution/dna_character_tree.py --input profiles.json --out artifacts/repository-evolution/affinity.json

Inference requires no Git SHA. Exact declaration names are assumed alignments; a separate observation-to-commit mapping is needed only for a later comparison with Git ancestry.
