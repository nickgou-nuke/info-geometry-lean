## 4. Source Sign Bug Identified & Repaired (`1_paste.txt` / Chunk 107)

During formalization of [`KleinianWittBornNullIncidence.lean`](../lean/InfoGeometry/Canonical/KleinianWittBornNullIncidence.lean), Lean kernel verification and Python cross-checks detected sign errors in the Source 1 / Chunk 107 `leftMulMat` / `octMul` table (components `4..7`, where the source table violated `Tr(L_x L_{ȳ}) = 8 octPolar(x, y)` and gave `L₁⋯L₇ = +I₈` instead of `-I₈`).

Replacing it with the standard Cayley–Dickson multiplication on `(ℍ, ℓℍ)` (`ℓ² = +1`):

```
(a, b)(c, d) = (a c + d̄ b, d a + b c̄)
```

restores all three identities in Lean:
- `oct_composition_left`: `L_x L_{x̄} = octNorm x • I₈`,
- `oct_universal_trace`: `Tr(L_x L_{ȳ}) = 8 * octPolar x y`,
- `volumeCl44_eq_chiral_diag`: `L₁⋯L₇ = -I₈` and `ω_{4,4} = diag(-I₈, I₈)`.
