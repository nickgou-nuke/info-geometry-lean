3. **Independent Quality Assurance Agent (`QA-A`, `SOP-001-C`)**:
   - Verifies that all `A-A` CAPAs are closed, checks SHA-256 artifact fingerprints, verifies that staged unrelated work (`git status --short`) and `.lake/packages/*` are untouched, and signs the final release disposition.

   - Enforces single-flight build lock discipline (`/tmp/info-geometry-build.lock` via [`tools/build_lock.py`](file:///home/goutev/repos/info-geometry-lean/tools/build_lock.py)), integrates `A-A`/`QA-A`-approved candidates into tracked owner files, and checkpoints task-owned edits with `git add -- <paths>`.
