## Status Values

- `package-owned`: canonical implementation already lives in `src/igf` or another package kernel.
- `package-candidate`: shared invariant should be moved into or re-exported by the package kernel soon.
- `wrapper`: compatibility entrypoint over a package API.
- `legacy-owned`: script-native lane remains the owner for now.
- `lean-owned`: Lean/Lake-owned exporter or tool module; Python should consume its artifacts, not replace it.
- `experimental`: active research/generative/orchestration edge; do not migrate until invariants stabilize.
- `archived`: historical surface only.

## Priority Values

- `P0`: shared config/env/path/artifact contract surfaces.
- `P1`: active production workflows already partially mirrored in `igf` or high-leverage graph/quality lanes.
- `P2`: useful but still script-native subsystem lanes.
- `P3`: experimental, low-frequency, or unstable orchestration.
- `P4`: archive only.
