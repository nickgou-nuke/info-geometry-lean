## Atomic claims and corrections

Write `D_u(x) = ux-xu`, `J_u(x) = ux+xu`,
`C_uv(x) = uxv+vxu`, `A_uv(x) = uxv-vxu`, `K=uv+vu`, and `S=uv-vu`.

The universal operator identities are:

```
J_u D_v + J_v D_u = D_K
D_u J_v - D_v J_u = J_S + 2 A_uv
D_u D_v - D_v D_u = D_S
J_u J_v + J_v J_u = J_K + 2 C_uv
D_u D_v + D_v D_u = J_K - 2 C_uv
```

The second identity corrects a false input equation: its signed sandwich term
cannot be discarded even for opposite square-zero Peirce corners. A full
3-by-3 matrix counterexample uses three off-diagonal inputs. The fourfold
readout follows without dividing by four.

On `A × A`, define `d_u(x,y)=(D_u(y),J_u(x))`. Then
`d_u² = lift(D_(u²))`. Thus `u²=0` gives `d_u²=0` and the native inclusion
`range(d_u) ≤ ker(d_u)`. In contrast, the undoubled adjoint has
`D_u²(x)=-2uxu`, which need not vanish. A noncommuting counterexample is
included. Neither identity alone is a Hodge theorem.

For `u²=v²=0`, put `E=u+v`, `J=u-v`. The proved relations include
`E²=K`, `J²=-K`, `JE=S`, `EJ=-S`, `S²=K²`,
`[S,E]=2KJ`, `[S,J]=2KE`, and `[S,[S,E]]=4K²E`.
The operator `K` commutes with the entire native subalgebra generated by
`u,v`; it is not generally central in the ambient matrix algebra.

For an arbitrary reciprocal cycle `[p,j]=e`, `[p,e]=j`, Leibniz gives
`[p,je]=e²+j²` and `[p,e²]=je+ej`. The conservation equivalences retain their
explicit cycle hypotheses. The difference `e²-j²` is conserved without an
anticommutation assumption. A reciprocal algebraic cycle is not a proof of
periodic motion or a scalar oscillation frequency.

Cyclic trace gives `tau(C_uv(x))=tau(Kx)` for every input, without requiring
`[p,x]=0`. For full real matrices, `v=uᴴ` makes the map positive in native
`Matrix.PosSemidef`; trace preservation additionally uses `uuᴴ+uᴴu=1`.
No claim of positivity is made for arbitrary unrelated `u,v`. No complete-
positivity classification, positive spectral gap, invertibility, mass theorem,
Maxwell equation, Schrödinger equation, or Lorentzian-signature theorem is
inferred from these ring identities.
