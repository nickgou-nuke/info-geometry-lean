## Relevant mathematical content

The paper uses the real split-octonion basis

```text
1, J₁, J₂, J₃, j₁, j₂, j₃, I
```

with

```text
Jₙ² = +1
jₙ² = -1
I²  = +1
```

and defines the pseudo-vector units by

```text
jₙ = 1/2 εₙₘₖ Jₘ Jₖ.
```

Its multiplication relations include

```text
Jₙ Jₘ = -Jₘ Jₙ = εₙₘₖ jₖ
jₙ jₘ = -jₘ jₙ = εₙₘₖ jₖ
jₘ Jₙ = -Jₙ jₘ = εₙₘₖ Jₖ
Jₙ I = -I Jₙ = jₙ
jₙ I = -I jₙ = Jₙ.
```

Conjugation is given by

```text
1† = 1
Jₙ† = -Jₙ
jₙ† = -jₙ
I† = -I.
```

For

```text
s = ω + λₙ Jₙ + xₙ jₙ + ct I,
```

the paper obtains

```text
s† = ω - λₙ Jₙ - xₙ jₙ - ct I
N(s) = s s† = ω² - λ² + x² - c²t².
```

Thus the split norm has signature `(4,4)` up to ordering/sign convention.

## G₂ content

The paper states that automorphisms preserving the split-octonion
multiplication form a subgroup of `SO(3,4)` and identifies the relevant
noncompact exceptional group as the real split form of `G₂`. It writes a
15-parameter infinitesimal transformation system and imposes one linear
constraint, leaving 14 independent parameters. It also states that the rank
is two.

This is useful for the repository as:

- an explicit basis/sign convention;
- a candidate coordinate form for infinitesimal automorphisms;
- an independent explanation of the 14-dimensional split `g₂` lane;
- a possible source for checking the existing derivation matrices.

## What the paper does not prove

The paper does not construct:

- an automorphism group functor over arbitrary rings;
- an affine group scheme;
- a natural equivalence with the split Chevalley group scheme;
- a proof that its 14 infinitesimal parameters exhaust all derivations;
- a global Lie-group integration or connectedness proof;
- a kernel/surjectivity proof for the full automorphism representation.

Therefore it cannot close the Lean target

```lean
Aut_R(SplitCayley) ≃* G2SplitRealPoints
```

by itself.

## Mathematical caveat

The paper says that the norm is “assumed to be non-negative”. That statement is not
correct for the unrestricted real split-octonion algebra: the split composition
norm is indefinite and has nonzero null vectors and zero divisors. The paper is
using a restricted physical-event interpretation, not changing the algebraic
signature. This must not be imported into the Lean norm theorem.
