### 4.1 Tripotent Matrices

**Definition:** T ∈ M₂(ℝ) is **tripotent** if:
```
T³ = T
```

**Note:** This is weaker than:
- **Idempotent:** T² = T (projectors)
- **Involution:** T² = I (symmetries)

### 4.2 Determinant Classification Theorem

**Theorem (Tripotent det split):**
```
T³ = T  ⇒  det(T) ∈ {0, 1, -1}
```

**Proof:**
```
det(T³) = det(T)³ = det(T)
⇒ det(T)³ - det(T) = 0
⇒ det(T)(det(T)² - 1) = 0
⇒ det(T) ∈ {0, 1, -1}
```
