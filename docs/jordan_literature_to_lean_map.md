# Jordan Corridor Literature-to-Lean Map

This note records the genuine external proofs supporting the remaining
`JordanNormalForm` bucket-3 claims, and maps each one to the current Lean owner
surface in the repo.

The point is not that the mathematics is missing. The point is that the Lean
formalization still needs the exact transport, packaging, and API wiring.

## What is genuinely open in Lean

The remaining debt is not “is this true?” but “prove it in the repo’s exact API”.

The current open items are:

- unconditional characteristic-polynomial proof for recursive Jordan block matrices
- unconditional Jordan existence theorem in the repo’s matrix-facing API
- unconditional PID-to-Jordan-basis reconstruction
- unconditional generalized-eigenspace transport theorem in the matrix-facing API

## Practical proof order

1. Close `jordanMatrix_charpoly` from the inductive Jordan block charpoly formula.
2. Use generalized eigenspace decomposition to close the span and finrank lemmas.
3. Route the `AEval'` statements through the PID structure theorem / cyclic decomposition.
4. Use the Jordan-Chevalley bridge for semisimple-plus-nilpotent splitting.
5. Keep the transport lemmas as packaging around those core results.
