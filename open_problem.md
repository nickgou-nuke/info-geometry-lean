## 3. Best dependency order

The file’s claims should not be attacked in the order they appear. A workable proof/open-problem hierarchy would be:

First, prove the ordinary algebra:

[
Cl(1,1),\quad P^2=T^2=1,\quad PT=TP,\quad \langle P,T\rangle\cong V_4.
]

Second, formalize Drazin linear algebra:

[
\Pi_D=I-LL^D,\quad \Pi_D^2=\Pi_D,\quad
\operatorname{range}(\Pi_D)=\ker(L^k).
]

Third, define the geometric objects precisely:

[
\operatorname{DrazinCore},\quad
\operatorname{TopologicalGapShadow},\quad
\operatorname{ModularSuperTorus},\quad
\operatorname{ConformalClosure}.
]

Fourth, prove only conditional compactification:

[
\text{lattice + bounded fundamental domain + Weyl/V₄ action}
\implies
\text{compact quotient}.
]

Fifth, build the operator theory:

[
\operatorname{DiracDrazin},\quad
\operatorname{SouriauDiracDrazin},\quad
\operatorname{SatisfiesSouriauKMS}.
]

Sixth, formalize Fierz emergence:

[
\psi\bar\psi
\mapsto
\text{grade-1 vector}
\mapsto
P_\mu.
]

Seventh, define the Mellin transform and prove a conditional spectral theorem.

Only after that should the Riemann-BPS correspondence, MaxEnt-RH equivalence, and cosmological-constant claims be attempted.

## 4. Statements that need rephrasing before becoming serious theorems

Several claims in the file are useful as hypotheses but unsafe as written.

“`Aut(Cl(1,1)) = V₄`” should become “the subgroup generated by the selected parity and time-reversal automorphisms is `V₄`.”

“Finite `V₄` symmetry compactifies translations” should become “given a lattice and bounded fundamental domain, quotienting by the selected Weyl/`V₄` action produces a compact sector.”

“The functional equation forces RH” should become “self-dual resonances under (s\mapsto 1-\bar s) lie on the critical line; proving all relevant resonances are self-dual is the hard open problem.”

“RH is equivalent to unique factorization” should become “inside the proposed label-collision model, critical spectral stability may imply injectivity of a prime-label map.” Ordinary unique factorization does not require RH.

“Dark energy is a theorem from modular residue” should become “define a modular Casimir/residue functional and test whether its scaling matches the proposed ((\ell_P/R_H)^2) law.”

[

\textbf{Spire Stability Conjecture:}
}
]

1. the selected parity/time-reversal automorphisms generate a `V₄` Weyl symmetry;

Then the stable Mellin resonances lie on the critical line:

[
\forall s\in \operatorname{MellinSpectrum}(Q),
\qquad
\operatorname{Re}(s)=\frac12.
]

In Lean-shaped form:

```lean
conjecture Spire_Stability_Conjecture
  (Q : SpinorField)
  (Torus : ModularSuperTorus)
  (op : SouriauDiracDrazin Q) :
  V4WeylCompatible Q Torus →
  DrazinCoreIsBPS op →
  SatisfiesSouriauKMS op Q →
  ∀ s ∈ MellinSpectrum (Ternaform_of Q), s.re = 1/2
```

That is the strongest mathematically extractable “main theorem as open problem” from the file.
