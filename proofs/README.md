## Installation and Usage

### Prerequisites

- **Lean 4**: Install via [elan](https://github.com/leanprover/elan) — `curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh`
- **Python 3.8+** with `numpy`, `scipy`, `sympy`, `mpmath`

### Building the Lean Proofs

```bash
cd proofs
lake update
lake build
```

### Running the SymPy Verifications

```bash
cd proofs
python3 TKKClosureErlangenGeometry.py
python3 ChiralGUEWignerDyson.py
python3 SpacetimeGUEIsomorphism.py
python3 BuresMetricClosedCartography.py
python3 riemann_hypothesis_ijirt172568.py
```

Add `--plot` to any script for visualization output.
