# Bridge Candidates

This file is a live template, not a frozen frontier snapshot.

## How to populate it

Regenerate candidates from:
- fresh semantic-block exports;
- current semantic quotient;
- current projection coloring;
- direct file analysis of the owner modules.

## Candidate selection rule

Keep only candidate lemmas that:
- belong to a lower owner file;
- would remove a real shell or packaging dependency;
- are not already implied by a current lower theorem under a different name.
