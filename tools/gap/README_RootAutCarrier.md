# RootAutCarrier GAP library

`RootAutCarrier.g` is a small, presentation-independent GAP library for
finite matrix carriers generated by two lists:

```gap
carrier := InfoGeometryRootAutCarrier.Build(pcGenerators,
  rootAutGenerators);
```

The library explicitly enumerates the closure using every generator and its
inverse.  The returned record contains closure elements, canonical generator
words, subgroup/carrier sizes, generator orders, and `rootAutInPC` membership.

Useful operations are:

```gap
InfoGeometryRootAutCarrier.Membership(carrier, elements);
InfoGeometryRootAutCarrier.Export(carrier);
InfoGeometryRootAutCarrier.PrintCertificate(carrier);
```

The export contract is deliberately explicit:

* matrices retain GAP's 1-based row/column order;
* words are lists of `[generator_index, exponent]` pairs;
* the closure enumerator multiplies generators on the left;
* Lean readback must translate indices to `Fin` and must preserve or
  intentionally reverse this word orientation.

The library is intended for finite carriers.  It does not infer a Lie
algebra, a derivation property, a norm invariant, or a Lean theorem from a
GAP certificate.

Run the executable smoke test from the repository root:

```sh
gap -q tools/gap/test_RootAutCarrier.g
```
